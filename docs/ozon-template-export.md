# Yandex 在线商品导出到 Ozon

在“在线商品 → Yandex Market”筛选并勾选在售 SKU，点击搜索按钮右侧的“操作 → 导出到 Ozon”。
单个与多个 SKU 共用“选择模板 → 检查商品 → 下载文件”流程；组合勾选仅选取当前筛选匹配的成员。
切换平台、店铺、筛选、页码或离开在线商品页会清除选择，避免携带旧列表商品。

上传从 Ozon 下载的空白 XLSX 类目模板，不超过 3 MB。使用 CNY 模板，类目直接从工作簿读取。预检按模板标注列出每个 SKU 缺少的必填资料，点击“编辑”即可补充。
商品类型使用模板预填值或字典中的唯一选项；有多个选项时可按 SKU 选择。

## 字段与事实来源

| Ozon 字段 | 来源与处理 |
| --- | --- |
| 货号 | 所选在线商品的 seller SKU / offer ID，保留文本和前导零 |
| 商品名称 | Yandex 名称；圣诞装饰品存在显式厘米规格且只有一处尺寸表达时按该 SKU 的成品宽高修正；可以手工编辑 |
| CNY 价格 | Yandex Business 账号基础价；其他币种须手工填写 CNY，不自动换汇 |
| 毛重 / 包装宽高长 | Yandex `offer.weightDimensions`；kg × 1000、cm × 10，非整数向上取整 |
| 品牌 | Yandex `offer.vendor`；“其他”、中俄文无品牌标记转换为模板的 `no_brand` 值并提示确认，缺失时要求补充。真实品牌保留；完整模板字典不含该品牌时阻止导出，字典缺失或不完整时提示到 Ozon 核对 |
| 型号名称 | 保留可用的 group ID，独立商品使用 SKU / offer ID。源值含中文时，只有当前店铺整个已同步分组的标题均为同一个俄文名称且不会与其他组重名，才复用该名称；否则要求手工填写。中文覆盖值和超长型号均阻止导出 |
| 主图 / 附图 | 优先选取 `mediaFiles.pictures` 中已上传成功的 `marketUrl`；失败图片排除，附图最多 14 张；无上传状态资料时沿用已有图片地址 |
| 条码 | 原 offer 的第一个条码；未提供则留空，不将 Yandex Market SKU 或本地编码当条码 |
| 颜色名称 / 长度 | 仅对圣诞装饰品使用已核对的规格代码；宽高一致且厘米单位明确时填写长度，其他情况留空 |
| 类型 | 与模板类目匹配的商品类型；不复制 Yandex 类目 ID |
| 加速评价收集 | 固定写入模板的“否”，覆盖空白模板默认的“Да” |
| Ozon SKU | 留空，避免把 Yandex Market SKU 当成 Ozon 商品身份 |

当前未映射的选填属性及简介留空，不从图片或多规格混合描述推测事实。
“编辑导出资料”只修改本次导出覆盖值，Yandex 快照、商品和草稿保持原样。
预检会展示缺失/无效必填字段、图片失败、条码缺失及 DIY 类目核对提示。
型号自动修正读取该店铺已同步的同组成员，不以当前勾选范围决定名称；不自动翻译或生成分组编号。
同组资料变化会重新参与下载前的预览校验；不能从本地快照判断尚未同步商品的分组资料。
模板未要求条码时可留空生成，但必须按 Ozon 实际上传反馈处理；“必填资料齐全”只表示本地检查通过。

## 模板与一致性

- 原表头说明、隐藏 configs/info/validation、字典、命名范围、单元格样式和数据验证保留。
  只替换主商品页中从商品起始行开始的数据，并扩展商品区域及筛选范围；不保留原模板默认商品行。
- 导出货号、条码和其他文本使用原生文本单元格，不执行输入中的 Excel 公式。
- 商品必须属于当前 Yandex 店铺且处于在售、详情完整状态。操作者核对所选商品与模板类目。
- 下载生成前重新读取快照，核对包含实际导出字段的预览摘要；商品、模板或店铺变化时要求重新检查。
- 模板和覆盖值通过请求传递，文件在内存生成并由浏览器下载，不持久保存模板、文件或新的业务状态。
- 全程不使用 Ozon 授权信息或 API；导出成功不代表已上传、审核通过或设置了库存。
