## 已确认的产品边界

- 用户自行部署，软件当前免费发行和使用基础功能；允许免费分享官方链接和未经修改的完整官方安装包。免费不等于开源或授权转售。
- 未来可推出可选收费高级功能，公司提供的 AI 服务按 Token 另行收费。具体价格和计费细则在启用收费前明确并取得确认，不在协议内预设金额或虚构已上线的支付能力。
- 用户自行接入第三方 API、自行充值并与服务商结算，公司不收取该第三方 API 的调用费用。
- 公司采集范围仅限硬件信息，不采集或向公司上传商品、订单、业务资料、AI 对话、生成结果等其他数据，不增加云端业务数据备份或模型训练授权。
- 用户确认硬件信息用于辅助分析软件错误和崩溃。计划字段为 MAC 地址、diskid、cpuid，实际启用前逐项确认必要性；本次没有扩大到错误日志或崩溃转储。硬件标识只辅助关联设备，不能单独还原崩溃原因。
- 硬件信息最长保存 3 个月，本文本按每条信息采集之日起算；目的提前实现或依法应删除时提前处理。既有记录的期限不因再次使用而刷新，备份不另行延长。该期限不适用于用户自行部署的业务数据库。
- 用户自行配置的店铺、AI API、图床等业务连接与向公司的硬件上报分开描述，不把第三方功能调用写成公司业务数据采集。

## 实现状态及尚待落实的事实

- 当前桌面入口 `front/desktop/main.cjs` 没有硬件信息上报或自动升级实现；文本如实说明当前状态。本次只修改正文及查看入口，不实现采集、上传、自动删除、计费或升级机制。
- 硬件接收服务器的国家或地区尚未确定；实际采集方式、频率、接收方和各字段必要性仍需与实现核对。隐私政策保留“启用前具体告知”的约束，没有虚构服务器所在地，也不授权提前采集。
- 硬件采集上线时需要落实相应选择、撤回、查询和删除渠道，以及包括副本在内的保留期限；查看文本不是同意。用于稳定性分析的设备关联应评估能否采用更少字段或替代标识，不能仅因协议列出三个字段就全部采集。
- 当前没有用户注册、初次接受、付费确认和同意留痕机制。协议写明明确确认或另行签署的成立方式，正式分发时需与实际订立流程衔接。
- Token 收费尚未确定费率、失败及重试计费细则、付款及退款规则。未来实现必须遵守当前不上传业务内容的边界；本次条款不授予公司接收 AI 对话或其他业务内容的权利，也不设定公司保存此类数据的期限。
- 联系邮箱及十五个工作日内回复处理结果或进展的承诺需要有人受理；该时限是本政策承诺，不表述为所有情形统一适用的法定期限。
- 本文为结合产品事实和公开来源编写的文本，未经律师审核，不标注为律师出具或主管部门认可。正式发行前宜针对最终采集实现与付费流程复核。
