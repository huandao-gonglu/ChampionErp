# 前端规范

本文件只记录 `front/` 的开发约定。全项目约束见 [AGENTS.md](../AGENTS.md)；业务契约按需查阅 [AI 上下文地图](../docs/ai-context-map.md)。

## 技术与职责

前端使用 Vue 3 SFC / `<script setup lang="ts">`、TypeScript、Vite、Pinia、Vue Router、Tailwind CSS 和 vue-i18n。依赖及版本以 [package.json](package.json) 和锁文件为准，使用 pnpm。

- 页面负责组合业务组件；共享状态按业务域放入 Pinia，局部编辑状态留在组件或 composable。
- 普通业务 HTTP 通过 `src/api/client.ts` 的 Axios 实例及 `src/api/` 领域封装调用。该实例处理语言、时区、presentation header 和错误归一化；成功响应由业务 API 解析。
- AI 对话及展示流使用现有 AI SDK transport，见 [AI Work 契约](../docs/aiworkpage.md)。不要从聊天文字或工具卡反解析业务结果。
- 后端共享契约通过 `scripts/generate_frontend_types.py` 生成 `workflow.generated.ts`，不手工修改生成文件；前端展示类型保留在 `src/types/`。
- 路由标题沿用 `meta.titleKey` 等既有元信息；用户可见文案优先使用现有 `zh` / `en` 语言资源。
- 样式沿用 `src/style.css` 和 Tailwind 主题，支持现有 `html.dark` 暗色模式；共享组件优先复用，弹窗手势遵守根目录约定。
- 不直接渲染未经处理的用户输入 HTML。需要富文本时明确清理边界；项目当前没有 DOMPurify 依赖，不能假定已经存在全局 HTML 清理器。

当前前端是 ERP 工作台及 AI Work，不包含登录/注册、支付或订阅系统。`components/auth/` 用于店铺和服务授权配置；API Client 没有 access/refresh token 刷新或 `{code,message,data}` 自动解包协议。

## 运行与构建

在仓库根目录使用 `scripts/dev.sh` 启动开发环境。单独操作前端时在 `front/` 执行：

```bash
pnpm dev
pnpm build
pnpm test:run
pnpm typecheck
pnpm types:check
pnpm lint:check
```

`pnpm lint` 会自动修改文件；覆盖率报告用 `pnpm test:coverage`。旧规范的 80% 覆盖率目标是否继续适用尚未确认，当前 Vitest 配置未设强制阈值。

- Web 构建输出到 `erp_web/static/dist`，由 Python `erp_web.server` 托管。
- Vite 默认端口为 3000；代理目标依次取 `VITE_DEV_PROXY_TARGET`、`ERP_PORT`，未设置时为 `http://127.0.0.1:5050`。代理路径以 [vite.config.ts](vite.config.ts) 为准。
- 桌面版使用 Electron；`pnpm build:desktop` 输出到 `front/dist-desktop`，打包命令见 `package.json`。桌面版另行连接 ERP 后端，其地址配置以 `desktop/main.cjs` 为准。

## 验证

单元与组件测试使用 Vitest、jsdom 和 Vue Test Utils，测试就近放置。按改动范围运行测试、类型或构建检查；后端共享 Schema 变化时同步生成并检查前端类型。
